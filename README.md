# Pizza
It's a silly game that I've been making to occupy myself during my free time. The goal is to collect the tasty ingredients for your pizza, to avoid bad ones, and to enjoy your creation after you cross the finish line!

I've made some of the assets myself (the ingredients and the skybox) and I've used some from the Unity asset store (character w/ animations, music), so during this project I have not only learned to work in Unity and to code in C#, but also the basics of Blender 3d modeling. I have been making this project while completing the "Junior Programmer" pathway on Unity Learn, it helped me to learn basic concepts of game making so that I could make my own project based on this knowledge.
